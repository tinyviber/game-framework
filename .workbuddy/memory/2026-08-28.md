## 2D 俯视角瓦片解谜游戏（5 阶段）— 基本可玩版本完成

- **Phase 1** Room+Tilemap：`src/world/tilemap.ts`（parseTileRoom 校验/冻结）、`camera.ts`（lerp 跟随+边界钳制）、`rendering/tile-scene.ts`（TILE_SIZE=48，色块渲染+可选 sprite）、`main.ts` 键盘+摄像机 ticker。
- **Phase 2** Transition：房间 JSON `exits {up/down/left/right:{room,spawn}}`；`world/tile-transition.ts` resolveTileExit（踩边缘出口格触发）；main 黑屏淡入淡出（FADE_MS=260 状态机）。room_01/02/03 互通。
- **Phase 3** Door+FlagSystem：`world/flags.ts` FlagStore（memory/localStorage 适配器，JSON 单 key 持久化，前缀 flag:/chest:/target:/latch:）；carried 状态（flags/openedChests/onTargetFired/latchedOpenDoors）随切房+刷新存活；console `setFlag('x',true)`/`getFlags()`；锁门挡路+占位提示。
- **Phase 4** 四机关全 JSON 配置：pressurePlates（踩/方块压住开联动门，松开关）、levers（E 互动切换）、blocks（四向推块，target 触发一次：setFlag/openDoors 永久锁存）、chests（开一次置 flag）；`world/event-bus.ts` 单通道类型化 pub/sub，main 接线发布事件。applyTileOperation 全有全无、拒绝按引用返回输入 state、deepFreeze。
- **Phase 5** Hub 组装：hub/vault/cellar 三房（hub 压板+方块守北门、cellar-gate 锁 cellar-key、cellar 拉杆开 treasure-door + 推块到位锁存 exit-door）；`world/hub-playthrough.test.ts` 端到端全流程；DialogueBox（DOM 文本框，Z 开/翻页/关，数据在 `src/data/dialogue.json`）。
- **评审修正**：hub 集群与 room_01 出生房连通（room_03 加 down 出口）；hub 北门走廊封墙防绕行；cellar 分层（拉杆门+推块门双门控出口）；open chest 不再短路邻居扫描；setFlag 幂等守卫。
- **贴图**：管线就绪（`rendering/tile-textures.ts`，Kenney Tiny Dungeon 192×144@16px 帧图，nearest 缩放，缺素材逐格回退色块）；本机网络出口被代理拦截无法下载 → 指引见 `public/assets/ATTRIBUTION.md`，放 `public/assets/tiny-dungeon/tilemap_packed.png` 即自动启用。
